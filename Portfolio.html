A level NEA For my NEA I created a platformer game called blok jump.It was based off of a game called doodle jump and similarily in this platformer there was only one vertical level which went on infinitley. The platform spawns are randomly placed through the level and for each platform that you jump on your character speeds up. The further you go in the level the more points you would gain. These would be saved to an account that you could log back into to see your highest score when you want to play again. In order to create the game I had to create a GUI for the login screen, main menu and actual game. I had to learn how to use the library tkinter for python in order to do this. I also learnt how to save data to an external file and how events work in python.
